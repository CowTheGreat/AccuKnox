# Assignment 3

[React Markerless AR on npm](https://www.npmjs.com/package/@cow-the-great/react-markerless-ar?activeTab=versions)

- At a hackathon, my team needed AR in a React app and had to rely on an external site to get it working.
- The hard part was combining a live camera feed with a Three.js scene that could render both static and animated 3D models.
- I wrapped that setup in reusable React components so developers could load a model and configure the scene through props.
